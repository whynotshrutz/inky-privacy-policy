Inky Privacy Policy

Last updated: November 8, 2026

Information Collection

Inky does not collect or transmit personal information to external servers. Selected text, webpage URLs, titles, and highlight colours are stored locally using Chrome Storage.

Data Storage

All saved highlights remain in the user's browser. Inky does not use external servers to store this information.

Data Sharing

Inky does not sell or share user data with third parties.

Permissions

Host permissions enable webpage highlighting. Storage permission allows users to save and retrieve highlights.
